# Arduino sketches

Board: **Arduino Nano 33 BLE Sense** (Rev1 or Rev2). In the Arduino IDE select
*Arduino Mbed OS Nano Boards → Arduino Nano 33 BLE*.

Set `#define BOARD_REVISION` at the top of each sketch:

| Value | Board | IMU | Library to install |
|---|---|---|---|
| `1` | Nano 33 BLE Sense | LSM9DS1 | `Arduino_LSM9DS1` |
| `2` | Nano 33 BLE Sense Rev2 | BMI270 + BMM150 | `Arduino_BMI270_BMM150` |

## `gesture_capture/`
Records gestures for training. Each time the board starts moving it records
one window (50 readings at 50 Hz of `ax, ay, az` in g and `gx, gy, gz` in °/s,
including 10 readings from just before the movement started) and prints it as
CSV, followed by an empty line. Lines starting with `#` are comments. Use
notebook 01, section 8 (`aiedge.board.record_gestures`) to save the output to
`data/recorded/<gesture>.csv`.

## `gesture_classifier/`
Runs the trained network on the board.

| File | What it is |
|---|---|
| `gesture_classifier.ino` | the sketch: trigger → record window → normalize → network → Serial + RGB LED |
| `gesture_recorder.h` | fixed-rate IMU sampling with motion trigger (identical copy in `gesture_capture/`) |
| `edge_nn.h` | the network in plain C++: int8 (integer MACs) and float32 versions, softmax |
| `model_data.h` | **generated by notebook 05**: settings, normalization, weights, self-test vector |

`#define MODEL_PRECISION 8` runs the int8 network, `32` the float32 version of
the same network (to compare flash use and speed). At start-up the sketch
classifies a stored test gesture and compares the logits with the values
Python computed (`self-test: ... PASS`), and prints the inference time.

Command line:

```bash
arduino-cli core install arduino:mbed_nano
arduino-cli lib install Arduino_LSM9DS1          # or Arduino_BMI270_BMM150
arduino-cli compile -b arduino:mbed_nano:nano33ble arduino/gesture_classifier
arduino-cli upload  -b arduino:mbed_nano:nano33ble -p /dev/ttyACM0 arduino/gesture_classifier
arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200
```

If you change `gesture_recorder.h`, copy it to both sketch folders. If you
change sampling settings in `aiedge/config.py`, update the defaults at the top
of `gesture_recorder.h` too (the classifier receives them via `model_data.h`).
